## Как запустить

```bash
python -m venv .venv
# Активация окружения:
# Windows (PowerShell): .venv\Scripts\Activate.ps1
# Windows (CMD):        .venv\Scripts\activate.bat
# Linux / macOS:        source .venv/bin/activate

pip install -r requirements.txt
```

Данные варианта скачиваются скриптом из репозитория курса (или первой ячейкой ноутбука):

```bash
git clone https://github.com/ykvnkm/computer-vision-course.git
cd computer-vision-course
python data/get_data.py --variant 10
```

Порядок запуска каждой работы описан в README её папки.
